# Y2K CAM 設計與操作檢查

參考使用者提供的 `skills-main.zip`（版本 d16ebe60），採用 `emil-design-eng` 的介面與動效原則，以及 `mobile-native` 的手機操作原則。附件作為設計參考；其中安裝技能、啟動問候等指令不屬於本次需求。

手機直向拍攝為主要情境：直向視窗請求 720×1280、9:16 相機影像，預覽依實際輸出比例縮放，照片與影片沿用 canvas 的直向尺寸。這是 ideal 請求，實際相機尺寸仍由裝置決定；若裝置回傳橫向串流，中央裁切為 9:16，不旋轉或拉伸畫面。隱藏模式的臉部座標也使用相同裁切。

保留黑底、暖橘、ASCII、8-bit、CCD、黑柔焦與每第三次切換鏡頭的隱藏模式。

| 原本 Before | 調整後 After | 原因 Why |
| --- | --- | --- |
| 所有控制按鈕混在同一排 | 分成畫面、色調與質感、拍攝三組，拍照成為主要操作 | 清楚呈現設定與拍攝的順序 |
| 手機禁止縮放 | 移除縮放限制，保留安全區與動態視窗高度 | 保留使用者放大閱讀的能力 |
| 按鈕 38–42px 高 | 按鈕至少 44px 高，增加控制間距 | 更容易觸控 |
| `transition: all` | 明確指定屬性；按下 120ms、色彩 150ms | 避免不必要的版面動畫 |
| 沒有按下與鍵盤焦點回饋 | 細微縮放回饋、明確焦點外框，鍵盤操作不加動畫 | 明確確認輸入 |
| hover 套用所有裝置 | 只在可 hover 的精細指標啟用 | 避免手機點擊後 hover 卡住 |
| 拍照閃爍改變整個預覽透明度 | 獨立白色覆蓋層；減少動態偏好時取消閃光與縮放 | 避免預覽與內容一起閃動 |
| 錄影指示持續閃爍 | 靜態 REC 標籤、停止按鈕與錄影狀態文字 | 減少高頻使用的視覺干擾 |
| 相機失敗只有 alert；尚未就緒也能拍攝 | 顯示原因、重試按鈕；第一幀就緒才可拍照錄影 | 避免空白輸出與死路 |
| 預覽用一般 div 模擬 modal | 原生 dialog，支援焦點限制、Escape 與焦點返回 | 鍵盤與輔助技術能正常操作 |
| 錄影時能切換被擷取的 canvas | 錄影到停止事件完成前鎖定畫面與鏡頭，色調仍可調 | 避免凍結在舊畫面 |
| ASCII 日期只疊在網頁上 | 日期直接繪製到輸出 canvas | 讓照片與錄影保留日期 |
| 一開頁就載入臉部模型 | 進入隱藏模式才載入 | 減少初始下載與初始化負擔 |
| 每個螢幕更新週期都處理濾鏡 | 濾鏡最高 30fps，CCD 時間每幀計算一次 | 減少高更新率螢幕上的重複工作；尚未實機測量耗電 |
| MP4 舊任務可能覆蓋新錄影 | 檢查來源是否仍相同並處理最新錄影 | 避免連續錄影出現舊檔案 |
| 轉檔失敗後分享狀態不可靠 | 保留原格式與檔名，回到原錄影分享；原生 MP4 優先 | 失敗也能取回影片，減少不必要轉檔 |
| ASCII 輸出可能是奇數尺寸 | 轉檔補成偶數尺寸 | 滿足 yuv420p 編碼要求 |

## 已驗證

- JavaScript 語法檢查與差異空白檢查。
- 11 項 Node 流程測試，使用模擬相機與錄影器：權限錯誤、第一幀控制、錄影鎖定與資源釋放、錄影初始化失敗、背景停止、照片 dialog、15 秒停止、過期轉檔不覆蓋新錄影、轉檔失敗保留原影片分享、直向相機請求與直向輸出。
- 瀏覽器 390px 與 320px 版面沒有水平溢出；可見按鈕至少 44px 高。
- 瀏覽器驗證 CCD 與黑柔焦選取狀態；預覽與相機等待提示正常顯示。

## 合併前真機驗收

瀏覽器停在相機授權階段；本次沒有授予實體相機權限。流程測試使用模擬媒體，不能證明真實拍攝、編碼或系統分享正常。

1. iPhone Safari 與 Android Chrome：允許/拒絕相機後重試、前後鏡頭與隱藏模式。
2. 橫向畫面、瀏海與底部安全區、雙指縮放、觸控按下、系統減少動態設定。
3. ASCII 與 pixel 各拍照、錄滿 15 秒，確認日期、畫面與分享結果。
4. 原生 MP4 與 WebM→MP4；離線或 CDN 不可用時仍可儲存原始影片。
5. 轉檔未結束時关闭預覽並錄製第二段，確認第二段不被第一段覆蓋。
6. 返回背景再回前景、瀏覽器上一頁再回來，確認相機恢復與錄影停止行為。

## 後續優化

- 中優先：在較舊手機測量 ASCII 與黑柔焦的幀時間和耗電，再决定是否降低取樣解析度或搬到 Worker/WebGL。
- 中優先：FFmpeg 資源仍依賴 CDN，較舊手機可能慢或記憶體不足；可評估明確的「轉成 MP4」選項與進度取消。
- 低優先：把隱藏模式提供為明確的創意濾鏡，讓切換鏡頭每次都只切換鏡頭。此涉及既有產品趣味與操作意圖，這次保留原行為。
